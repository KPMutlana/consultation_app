# Consultation Booking Application

## Overview
The Consultation Booking Application is a Flutter-based system designed to allow students to schedule and manage consultations with lecturers. The application integrates Firebase Authentication and Firestore for secure user management and real-time data storage.

The system follows MVVM architecture to maintain clean separation between UI, business logic, and data handling.

---

## Features

### Student Portal
- User registration with validation
- Secure login authentication
- Dashboard displaying consultation bookings
- Create new consultation bookings
- View consultation details
- Edit or delete bookings
- Profile management and updates
- Real-time Firebase data synchronization

### Admin Portal
- Admin authentication
- View all student bookings
- Booking management functionality

## CRUD Functionality
- Create: Add consultation bookings
- Read: View bookings and dashboard
- Update: Modify bookings and profile information
- Delete: Remove consultations

---

## Architecture
The application follows MVVM architecture:

UI → ViewModel → Firebase Services → Firestore Database

This structure ensures scalability, maintainability, and clean separation of responsibilities.
